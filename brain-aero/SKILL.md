# brain-aero

Версия навыка: 2026-11-19 · Исходник: `aero-skills/brain-aero/SKILL.md`

`brain.py` строит локальный инкрементальный индекс текстов проекта в SQLite/FTS5. Он дополняет `pm.py`: карта загружается официальным `pm.load()`, а правила доступны через `q rules` и `q node`. Поиск использует BM25, заголовок имеет больший вес, конфиг может задавать синонимы. Ответы — указатели на источник, не длинные копии документов.

## Источники

Подключаются в JSON-конфиге: `manual`, `handoff`, `kb`, `map`, `wf`, `issue`, `todo`. `issue` — только локальная SQLite loop-watch: читаются события `issue` и `comment`, соединение read-only/query-only. `todo` — необязательный UTF-8 файл чек-листа, по одной записи на задачу. Путь и набор источников задаёт пользователь в локальном конфиге; личные данные, тексты закрытых источников и пути к ним нельзя добавлять в открытые файлы или коммиты.

Пути источников и базы разрешаются относительно каталога конфигурации. `map` обрабатывается кодом инфоцентра, второй парсер карты здесь не используется. Источники не изменяются. Если настроенный источник временно недоступен, прежние индексированные фрагменты сохраняются; чтобы удалить источник из базы, уберите его из конфигурации и запустите `build`.

## Команды

Запускать из каталога `brain-aero`:

```text
python brain.py build [--full] [--verbose] [--config PATH]
python brain.py find QUERY [--kind KIND] [--since YYYY-MM-DD] [-n N] [--config PATH]
python brain.py brief QUERY [-n N] [--config PATH]
python brain.py eval [PATH] [-n N] [--config PATH]
python brain.py stats [--config PATH]
python brain.py check [--config PATH]
python brain.py node ASSET_ID [--config PATH]
```

- `build` индексирует только изменившиеся файлы; `--full` пересобирает базу.
- `find` ищет по словам/синонимам, фильтрует по типу и дате; `--since` исключает фрагменты без даты.
- `brief` выдаёт свежие issue и передачи и только открытые задачи из настроенного TODO.
- `node` показывает карточку ресурса, его потоки, связанные правила и найденные фрагменты источников.
- `eval` читает локальный набор строк `K|source:location|query` / `P|source:location|query`. Для ручных и передач можно указать раздел: `manual:file.md#часть заголовка`, `handoff:file.md#часть заголовка`. Комментарии `# baseline|kind|method|K_hits/total|P_hits/total` печатают рядом сравнительные результаты.
- `check` проверяет источники, даты, целостность SQLite/FTS и осиротевшие ссылки; `stats` показывает размеры индекса.

Сначала скопируйте `brain.config.example.json` в игнорируемый Git файл `brain.config.json`, поправьте пути и при необходимости добавьте свои локальные источники. Не помещайте пользовательский конфиг, базу и eval-набор в коммит: `brain.config.json`, `brain.db` и `eval.txt` — производные/локальные файлы.

После добавления или изменения передачи запускайте `python brain.py build`; для проверки используйте `check`, `stats` и нужный запрос `find`/`brief`.
