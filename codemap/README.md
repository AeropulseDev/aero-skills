# codemap

Универсальный генератор карты кода: **Python, Google Apps Script, JS, HTML (`<script>`)**. Один скрипт `codemap.py`, только стандартная библиотека (Python 3.9+), ничего не исполняет и не импортирует. Заменяет разрозненные `genmap`-скрипты по проектам.

```
python3 codemap.py <root> [<root2> …] [--out X.md] [--json X.json] [--overview X.md] [параметры]
python3 codemap.py diff a.json b.json [--out diff.md]
```

## Что в карте
- **Файлы → классы / методы / функции**: строка, сигнатура (`-> тип`), декораторы, первая фраза докстринга (JS/GAS — комментарий строго над функцией).
- **Роуты HTTP** (отдельная таблица): FastAPI `@router.get|post|put|delete|patch|…`, `APIRouter(prefix=…)` (в пути выводится полный путь), `dependencies=[Depends(...)]` на роутере/декораторе/параметрах, `app.include_router(...)` (в строке «Подключает роутеры»), aiohttp `app.router.add_get(...)`, `web.get(...)`.
- **Хендлеры бота** (aiogram 3): `@router.message|callback_query|inline_query|…(фильтры)`, `router.message.register(fn, …)`; **FSM** — `StatesGroup` с состояниями.
- **GAS/JS**: `function`, `const f = () =>`, константы `UPPER_CASE`, триггеры (`doGet`, `doPost`, `onOpen`, `onEdit`…), вызовы сервера из HTML (`google.script.run.fn`), строки-пути к API.
- Константы модуля `UPPER_CASE`.

## Параметры
| Параметр | Что делает |
|---|---|
| `roots…` | папки проекта; несколько — карта по разделам (Python + GAS) |
| `--out X.md` | файл Markdown (без параметра — в stdout) |
| `--json X.json` | модель карты для `diff` |
| `--no-md` | не выводить Markdown (только `--json` / `--overview`) |
| `--overview X.md` | таблица «файл · строк · функций · назначение» |
| `--title`, `--about` | заголовок H1 и одна фраза «о чём» (требование manuals/AGENTS.md) |
| `--regen "команда"` | команда пересборки для шапки (без параметра — собирается из аргументов) |
| `--files-desc F` | sidecar с описаниями (по умолчанию `<root>/codemap.files.md`) |
| `--require-desc` | ошибка, если у файла нет описания в sidecar |
| `--lang py,gs,js,html` | какие языки брать |
| `--include / --exclude МАСКА` | пути, папки или маски (можно повторять) |
| `--depth N` | `1` — только файлы корня; `0` — без ограничения |
| `--nested` | включать вложенные функции (по умолчанию — верхний уровень, методы и вложенные хендлеры/роуты) |
| `--full-doc` | описание — весь докстринг, а не первый абзац |
| `--max-doc`, `--max-sig` | длина описания / списка аргументов в таблице (200 / 90) |

По умолчанию пропускаются `.git`, `.venv`/`venv`, `__pycache__`, `node_modules`, `secrets`, `tmp`, `dist`, `build`, `alembic/versions`, скрытые папки. Читаются только `.py .gs .js .mjs .html .htm` до 2 МБ: `.env`, `*.json`, ключи не открываются.

## Sidecar `codemap.files.md`
Лежит в проекте, описывает файлы вручную (пересборка карты его не затирает):
```
## О чём
Одна фраза под заголовком (вместо `--about`).

## Вступление
Любой Markdown — вставляется после шапки (потоки данных, порты, авторизация).

## Файлы
service.py: FastAPI-приложение, авторизация X-API-Key.
invoice_*.py: маска — одно описание на группу.

## Прочее
Любой Markdown — вставляется в конец карты.
```
Порядок строк в «Файлах» = порядок файлов в карте (не перечисленные — после, по алфавиту). Без разделов весь файл — список «путь: описание».

## Вывод Markdown (правила manuals/AGENTS.md)
`# Заголовок` → фраза «о чём» → `Обновлено: … · Источник: … · Регенерация: …` → вступление → таблицы роутов / хендлеров / FSM → «Файлы и функции» → «Прочее».

## Сравнение версий
```
python3 codemap.py project_a --json a.json --no-md
python3 codemap.py project_b --json b.json --no-md
python3 codemap.py diff a.json b.json --out diff.md
```
Отчёт: сводка; роуты и хендлеры (+/−/~); новые и удалённые файлы; изменения в общих файлах (сигнатура, декораторы, роут, фильтры хендлера, состояния FSM). Номера строк и докстринги не сравниваются. Добавлено — то, что есть в `b`, но нет в `a`.

## Ограничения
- Роуты распознаются статически: динамическая регистрация (`getattr`, циклы) не видна; `Deps` — зависимости, видимые в файле роутера и в вызове `include_router`.
- JS/GAS — регулярные выражения: функции верхнего уровня, без классов и методов.
- Не-Python в `.html` — только содержимое `<script>` без `src`.
