# skills-index — указатель навыков

Один навык для всех: агент сверяет задачу с облаками ключевых слов и грузит только подходящие навыки. Индекс собирается из двух реестров.

| Файл | Что | В git |
|---|---|---|
| `SKILL.md` | Инструкция для агента (общая) | да |
| `registry.open.md` | Открытые навыки этого репозитория | да |
| `registry.closed.example.md` | Шаблон личного реестра | да |
| `registry.closed.md` | **Ваш** реестр закрытых и командных навыков | **нет** (`.gitignore`) |
| `build.py` | Сборка установленной копии → `INDEX.built.md` | да (результат — нет) |

## Как завести свои закрытые навыки
1. Создайте частную папку рядом с проектами (например, `my_closed_skills/`), лучше — частный репозиторий на **своём** аккаунте. Не внутри aero-skills и не в репозитории команды.
2. Навык — папка `my_closed_skills/<имя>/SKILL.md`; данные навыка (списки, заметки) — в его же папке, не в корне.
3. В `SKILL.md` после заголовка строка `Версия навыка: ГГГГ-ММ-ДД · Исходник: <путь>`.
4. `cp registry.closed.example.md registry.closed.md` и добавьте запись с меткой `закрытый` и путём к папке. Командные навыки (из репозиториев вашей команды) — туда же с меткой `командный`.
5. `python3 build.py` и установите собранную копию (ниже).
6. `registry.closed.md` и `INDEX.built.md` не коммитятся. Чтобы не потерять реестр — держите его копию в своей частной папке.

## Установка
- **Claude Code:** `python3 build.py`, затем `INDEX.built.md` → `~/.claude/skills/skills-index/SKILL.md`.
- **Claude (приложение):** попросите агента «обнови skills-index из сборки» — он покажет карточку сохранения навыка.
- **Другие агенты:** в файле инструкций агента одной строкой: «начни с `aero-skills/skills-index/SKILL.md` и его реестров».

Агент сам сверяет версии (`Версия навыка`, `Версия реестра`) при каждом использовании и подскажет, когда пересобрать.
