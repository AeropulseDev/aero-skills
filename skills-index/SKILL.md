# Указатель навыков

Версия навыка: 2026-10-20b · Исходник: `aero-skills/skills-index/SKILL.md` (https://github.com/AeropulseDev/aero-skills). Навык один на всех; личное — только в закрытом реестре.

## Из чего состоит
- `SKILL.md` — эта инструкция, общая для всех.
- `registry.open.md` — реестр открытых навыков этого репозитория. Публичный, коммитится.
- Закрытый реестр — личный реестр закрытых и командных навыков пользователя. **В aero-skills не хранится**: лежит в частной папке пользователя (с историей в его частном репозитории). Где он — `build.py` узнаёт по переменной окружения `SKILLS_CLOSED_REGISTRY` или по одной строке-пути в `registry.closed.path` (этот файл в `.gitignore`); запасной вариант — `registry.closed.md` рядом (тоже в `.gitignore`). Шаблон — `registry.closed.example.md`.
- `build.py` — собирает установленную копию: этот файл + оба реестра → `INDEX.built.md` (тоже в `.gitignore`, в нём закрытые записи).

Индекс = записи обоих реестров. При совпадении имени запись закрытого реестра главнее.

## Как пользоваться
1. В начале задачи взять индекс. Если в загруженной копии есть разделы «Реестр …» — это собранная копия, работать по ней. Иначе прочитать `registry.open.md` из папки `skills-index` и закрытый реестр по пути из `registry.closed.path` (локальный клон aero-skills или подключённая папка).
2. Сверить запрос с облаками слов. Совпадение — загрузить навык (Skill) и работать по нему; несколько — загрузить все подходящие; нет — работать обычно.
3. Загрузив навык — сверить его версию (ниже).

## Метки доступа
- **открытый** — можно публиковать; лежит в aero-skills; запись — в `registry.open.md`. Без личных путей, аккаунтов и данных.
- **командный** — лежит в репозитории команды, видят коллеги и их агенты; запись — в закрытом реестре (у каждого свой).
- **закрытый** — только владелец, в его частной папке/репозитории; запись — в закрытом реестре.
- Граница: в открытых и командных файлах, коммитах, PR и issue не упоминать закрытые навыки, их пути и данные. Метка неясна — спросить владельца (догадка первой).

## Формат записи
```
## <имя> — <коротко>
Доступ: открытый | командный | закрытый · Исходник: <папка навыка> · Версия: ГГГГ-ММ-ДД
Что: …
Когда: …
Облако: ключевые слова (рус/англ, сленг, опечатки, тексты ошибок)
```
Коротко — индекс читается каждый раз. Старые имена и историю не хранить. Первая строка реестра после заголовка — `Версия реестра: ГГГГ-ММ-ДД`.

## Новый или изменённый навык
1. Запись в нужный реестр (по метке), поднять «Версия реестра» и «Версия» записи.
2. Открытый реестр и `SKILL.md` — коммит в aero-skills; закрытый реестр — коммит в частный репозиторий пользователя, в aero-skills никогда.
3. Пересобрать установленную копию (ниже) и предложить её пользователю (в Claude — карточкой сохранения навыка).

## Сверка версий — при каждом использовании навыка
- В каждом исходнике `SKILL.md` строка `Версия навыка: ГГГГ-ММ-ДД · Исходник: <путь>`; правка навыка → поднять дату.
- Загрузив навык, если папка исходника доступна: одной командой `grep -m1 '^Версия навыка' <исходник>/SKILL.md` сравнить с загруженной копией. Совпадает — молча дальше. Отличается или строки нет — одной строкой сказать «навык <имя> устарел: загружена <X>, в исходнике <Y>», работать по исходнику и предложить обновить копию.
- Для самого указателя сверять три строки: «Версия навыка» в `SKILL.md` и «Версия реестра» в обоих реестрах (`grep -m1 '^Версия' …`) с собранной копией. Разошлись — пересобрать (`python3 build.py`) и предложить обновить.
- Исходник недоступен — ради одной сверки доступ не запрашивать, работать по загруженной копии.

## Установка и сборка копии
- `python3 skills-index/build.py` → `skills-index/INDEX.built.md`.
- Claude Code: `INDEX.built.md` скопировать в `~/.claude/skills/skills-index/SKILL.md` (после каждой пересборки).
- Claude (приложение): агент читает `INDEX.built.md` и предлагает его карточкой сохранения навыка «skills-index» (заменяет целиком) — нажать «Сохранить».
- Другие агенты (Codex, Cursor, Gemini…): копия не нужна — читать `SKILL.md` и оба реестра прямо из клона.
