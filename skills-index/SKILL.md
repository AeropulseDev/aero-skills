# Указатель навыков

## Как пользоваться
1. В начале задачи сверить запрос с облаками слов ниже. Совпадение — загрузить навык (Skill) и работать по нему. Нет совпадения — работать обычно.
2. Несколько совпадений — загрузить все подходящие (например, loop-watch + git-repo-context-economy).
3. При создании или изменении навыка добавить/обновить его запись здесь — предлагать вместе с самим навыком, одной карточкой propose_skills.
4. Формат записи: имя, «что», «когда», облако ключевых слов (рус/англ, сленг, опечатки, тексты ошибок). Коротко — указатель читается каждый раз. Старые имена и историю переименований не хранить.
5. Свои закрытые навыки добавляйте в личную копию указателя, не в публичную.

## loop-watch — дешёвое наблюдение за GitHub
Что: `watch.py` по `config.yaml` следит за issue, новыми issue, коммитами ветки и PR; режим token (REST API, без модели) или browser (встроенный браузер, только issue); новое пишется выжимками в `inbox.md`; запуск по расписанию.
Когда: «следи за issue», «что нового в репозитории», уведомлять о комментариях, коммитах, PR; настройка запланированной проверки.
Облако: loop-watch, наблюдатель, следи, слежение, мониторинг, watch, issue, комментарии, новые issue, коммиты, PR, pull request, inbox.md, config.yaml, state.json, watch.py, probe.js, github_token, токен, token, browser, по расписанию, раз в час, уведомление, что нового, active_hours, часовой пояс.

## git-repo-context-economy — экономия контекста при работе с GitHub
Что: правила чтения issues/PR/комментариев через gh, git, GitHub API без раздувания контекста: фильтры в запросе, сабагенты для сквозных проходов, батчинг, сводки решений в project docs, учёт того, где выполняется команда (device_bash).
Когда: разбор issues, PR, ревью, комментариев, состояния репозитория, массовые запросы к GitHub API.
Облако: issues, issue, PR, pull request, пулреквест, ревью, review, комментарии, gh, GitHub API, REST, search API, label, milestone, state, since, per_page, пагинация, фильтр, сабагент, subagent, батч, параллельные запросы, decisions log, сводка, project docs, project_write, контекст, токены, экономия, git fetch, device_bash, где выполняется команда.
